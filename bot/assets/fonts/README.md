# Bundled fonts

`DejaVuSans.ttf` and `DejaVuSans-Bold.ttf` are bundled so Pillow banners render
identically on Windows (local dev) and Render (Linux, no apt access).

- Source: DejaVu Fonts 2.37 (`dejavu-fonts-ttf` 2.37.3)
